# Recursos gráficos de AlcoLock

Reemplaza los archivos de `static/img/` conservando exactamente estos nombres si deseas mantener el código sin cambios:

- `logo-alcolock.svg` → logotipo/escudo de AlcoLock.
- `peru-minedu.svg` → bloque de identidad Perú / MINEDU.
- `bus.png` → imagen principal del bus.
- `dispositivo.png` → imagen del dispositivo AlcoLock.
- `icons.svg` → referencia para iconografía del sistema.

Los archivos incluidos son **placeholders**. Puedes sustituirlos por tus imágenes finales.

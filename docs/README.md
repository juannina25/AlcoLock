# AlcoLock - GitHub Pages

Esta carpeta está preparada para publicar el prototipo en GitHub Pages usando `docs` como carpeta de publicación.

En GitHub: **Settings → Pages → Deploy from a branch → main → /docs**.

La versión publicada funciona como prototipo estático y guarda los registros en `localStorage` del navegador. La conexión real con el dispositivo y un backend central se integrarán posteriormente.
